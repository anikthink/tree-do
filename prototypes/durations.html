Start and end times

Five ways a task could take up time on the Hours view, from 15 minutes to 4 hours. They all use the same three days and the same tasks. Each one works, so try it in place.

DragQuick lengthsType itEstimate firstDay budget

1Drag

Like Google Calendar. Drag down an empty column to make a task as long as you drag. Drag a task to move it, and drag its bottom edge to make it longer or shorter. Everything snaps to 15 minutes.

Feels like
Google / Apple Calendar
Weak spot
Fiddly on phones

Try: drag on empty time · drag a task · drag a task's bottom edge

2Quick lengths

Tap a time and pick how long from a row of chips: 15m, 30m, 45m, 1h, 2h, 4h. Tapping a task brings the same chips back. You never drag, so it works the same with a mouse, a finger or the keyboard.

Feels like
A timer app
Weak spot
Odd lengths need "Other"

Try: click a task, then a length · click empty time

3Type it

Write the length the way you'd say it, in the add field you already use: dentist 3-4:30pm thu, call mum 6pm for 20 min. Clicking a task shows exact Start and End fields and works out the length.

Feels like
Tree-do's add field
Weak spot
You have to know the syntax

Try: type and press Enter · click a task to edit its start and end

4Estimate first

Say how long something takes before deciding when. Tasks with an estimate wait on the left, each with a bar showing its length. Drag one onto the grid and it takes up exactly that much time, which is time-blocking.

Feels like
Time-blocking planners
Weak spot
Two places to look

Try: drag a card from the left onto a day

5Day budget

Each day shows how much of it is already planned, split by list, against a set number of planned hours. Select a task and use −15 / +15 to change its length. The day tells you when you've planned more than fits.

Feels like
A spending budget
Weak spot
Less direct than dragging

Try: click a task, then use −15 / +15 · watch the day's meter
